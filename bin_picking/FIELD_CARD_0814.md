# 🥇 1순위 — 배경재 판정 (30분) 🚨 **본촬영의 게이트**

## 왜: 눈으로는 못 고른다. **가시광 차광 ≠ 850nm 흡수.**
검게 보여도 근적외선을 반사하면 배경이 depth로 채워져 **c3(F1 0.0000)** 가 된다.
⇒ 깔고 찍어서 **수치로** 판정하는 것이 유일한 방법.
🚨 **이걸 건너뛰고 30장을 찍으면 전부 버릴 수 있다.**

맥 터미널:
```bash

cp bin_picking/tests/check_background_material.py ~/Desktop/
```

⚠️ `git pull`에서 충돌·"local changes"가 나면 **덮어쓰지 말 것** → scp로 파일 2개만 우회.

⭐ 날아가는 것은 카메라가 아니라 **맥 랜포트 IP**다(카메라는 Static). 이 한 줄이면 복구된다.

## 1-2. 🔴 배치 — 여기서 결과가 갈린다

- **차광 용지를 테이블에 깐다** → 그 위에 **공구상자**를 올린다 → 상자 안에 부품
- 🚨 **용지는 빈 자리를 통째로 덮어야 한다(66.5×68cm 이상)**
  인식 영역이 450mm에서 **823×464mm**라 상자(450×270)만으론 화면 절반이 맨 테이블이다
- 🚨 **종이는 말리고 주름진다** → 평평하게 눌러 고정. 주름은 depth에 무늬를 만든다
- ⚠️ **이음매가 생기면 depth에 줄무늬** → 한 장으로 덮는 것이 최선

### 판정 기준

| 결과 | 뜻 | 행동 |
|---|---|---|
| 🟢 **유효율 4~8%대** | c1(학습 조건) 재현 | ✅ **본촬영 GO** |

**본촬영을 강행하지 말 것.** 대신:

2. 그래도 안 되면 → **무광 검정 시트지를 데이터와 함께 재요청**

3. 🥈로 넘어가지 말고 **🥉 IPC로 순서를 바꾼다**(촬영은 자재 재확보 후)

## 문제 대응

**A. 카메라가 안 열린다**
`sudo python bin_picking/tests/setup_camera_net.py --apply` → 그래도 안 되면
`arp -an | grep <MAC>`로 L2 확인. ⭐ **열거는 되는데 열기만 timeout이면 대역 불일치**
(카메라 IP 대역 = 꽂힌 랜포트 대역).

**B. DIST가 3000 근처로 뜬다** (실제 50cm인데)
→ `--raw-is-mm` 플래그. 저장 원본은 어느 쪽이든 raw라 안전.

**C. 판정 도구가 죽는다**
`--with-baseline` 없이 먼저 돌려볼 것(기준선 로드가 문제일 수 있음).
