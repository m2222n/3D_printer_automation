## STEP 1. 세션 A = 학습셋 60장 (오전)

```
sudo python bin_picking/depth_track/scripts/blaze_ace2_capture_dual.py \
     --session A --target 60 --out ~/Desktop/dual_capture_0824
```

### 🚨 카메라를 못 찾으면

| 증상 | 대응 |
|---|---|
| Blaze 못 찾음 | `--blaze-ip <주소>` 로 직접 |
| **ACE2 못 찾음** | STEP 0 다시 → 그래도면 `--ace2-ip <주소>`. 🚨기본 대역은 `192.168.30.x` |
| 화면 깨짐·프레임 유실 | `--throughput 15` → 안 되면 `10` |
| DIST가 3000 근처 | `--raw-is-mm` |

🚨 **ACE2가 안 열리면 스크립트가 일부러 멈춘다.** 오늘 목적이 RGB라
depth만 조용히 쌓이면 하루가 날아간다. 정말 포기할 때만 `--allow-no-rgb`.

### 세팅
1. **8/18 그 자리 · 그 상자** 그대로 · 🚨 **형광등 ON 유지**
2. **ACE2도 같은 장면**을 보게 — 화면 **오른쪽에 컬러가 같이 뜬다**
   ⭐ 두 화면에 **같은 부품이 보이는지** 눈으로 확인(7/29에 화각차로 depth 86%가 ACE2 밖이었다)
3. B그룹 7종 넣기(1종 1개) → **DIST med = 450~460mm** 맞추기
4. 🚨 맞으면 **카메라·상자는 이후 절대 손대지 않는다**

## STEP 2. 🚨 첫 장 판정 (여기서 멈출 수 있다)

화면 숫자 4개를 본다:

| 확인 | 합격선 |
|---|---|
| DIST med | **450~460mm** |
| BAND | **8k 이상** (화면에 `8k`+) |
| 🆕 **RGB bright** | **30~225** (너무 어둡/밝지 않게) |
| 🆕 **RGB sharp** | **50 이상** (초점) |
| 👁️ **눈** | 왼쪽=배경 검고 부품 선명 / **오른쪽=컬러가 또렷** |

- 하단에 **`SAVE OK`** 초록으로 뜨면 통과
- 🔴 RGB NG → 노출 문제면 `--ace2-exposure 8000` 같이 고정해 본다
- 🚨 **여기서 통과 안 되면 60장 찍지 말 것.** 조건 틀린 60장 = 0장
