## 1. 맥으로 받아서 실행

```bash
# ① 6000 → 맥 (label_png 만. 4.7MB)
#    🔒 접속 정보(계정·IP·포트) = memory/reference_dev_environment.md 참조
rsync -av -e "ssh -p <PORT>" \
  <USER>@<DEV_SERVER>:/data/jtm/dual_capture_0824/label_png \
  ~/Desktop/dual_capture_0824/

# ② 받았는지 확인 — 90 이 나와야 한다

ls *.png | wc -l

# ③ 실행
labelme . --labels labels.txt --output ./labelme_json --nodata
```

🚨 **`-z` 플래그 금지** — 맥 rsync 2.6.9 호환 문제(환경 문서 명시). `-av`만 쓴다.

🚨🚨 **①을 건너뛰면 안 된다** — 8/25에 실제로 이 사고가 났다.
`cd`가 실패했는데 **쉘은 이전 디렉토리에 그대로 있었고**, 그 자리에서 labelme를 켜서
**리포 안의 엉뚱한 이미지**가 열렸다. ⇒ ⭐ **②의 `90`을 눈으로 확인하고 나서 ③으로 간다.**
(`cd` 실패는 조용하다 — 프롬프트만 보고 넘어가면 모른다)

⭐ RGB도 참고용으로 받으려면 `--include='*_rgb.png'`를 따로 (180MB급이라 필요할 때만).

⚠️ **사무실 Wi-Fi(`OrinuAI_5GHz`)는 AP isolation이라 맥→6000이 막힐 수 있다**(7/16 확인).
timeout 나면 → A100 경유(`scp -P 2222 root@114.110.133.5`) 또는 핸드폰 핫스팟.

## 2. 🚨 그리기 규칙 — 8/19와 동일 (여기서 틀리면 F1이 조용히 왜곡된다)

1. ⭐⭐ **반드시 `polygon`으로, 첫 점을 클릭해 닫을 것**
   - 닫지 않고 Enter → `linestrip`(열린 선)으로 확정된다
   - 평가기는 **`polygon`/`rectangle`만** 마스크로 만든다 ⇒ 열린 선은 **GT에서 통째로 빠지고**,
     모델이 맞게 찾아도 **FP로 집계되어 precision이 억울하게 떨어진다**
   - 🔴 **8/5에 실제로 밟았다** = 299개 중 **23개**가 이 형태였다
2. **부품이 잘려 두 조각으로 보여도 한 부품이면 한 폴리곤** (A그룹에서 자주)
3. **부품끼리 닿아 한 덩어리로 보여도 부품 수만큼 따로** (B/C그룹에서 자주)
