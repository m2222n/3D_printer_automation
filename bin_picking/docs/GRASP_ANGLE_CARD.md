# 파지 자세 보정 카드 — 회전 부호 · 회전 오프셋 · 파지 깊이 (2026-09-26 작성)

> **무엇을 정하나** = 인식 좌표로 집을 때 남은 미지수 3개(`cam_to_base` 의 `rz_sign` · `rz_offset` · `z_offset`).
> 문서로는 못 정한다(HCR 오일러 규약 · 조우가 툴 X/Y 중 어느 축으로 닫히나 · 조우 끝과 TCP 사이 거리).
> **🥇 카메라 없이 로봇만으로 잰다** ⇒ 9/28(월) 로봇 단독 날에 끝낼 수 있다. 9/30 은 확인 1회만.
> 계산기 = `bin_picking/tests/grasp_angle_calc.py` (자체 시험 294/294 · 실제 `rz_for_grasp` 와 맞물리는지까지 검사)

**왜 로봇만으로 되나**
- 회전: 코드는 `rz = rz_sign × yaw_close + rz_offset` 을 보낸다. `yaw_close` = 조우 선이 base +X 와 이루는 각.
  ⇒ 로봇에 RZ 두 값을 주고 조우 선이 어디를 향하는지 보면 두 미지수가 풀린다. 카메라 쪽 각도 변환은 3점법 행렬이 정확히 한다.
- 깊이: 3점법 로봇 점은 **닫힌 조우 끝을 블록 윗면에 댄 TCP**(실행표 v5 4-4). 그래서 카메라가 준 윗면 z 도 "조우 끝이 윗면에 닿는 TCP z" 로 나온다.
  ⇒ 같은 방식으로 부품 윗면에 대고, 집는 높이까지 내린 차이만 재면 된다. 조우 끝↔TCP 거리는 상쇄된다.

**준비물** = 마스킹 테이프 · 펜 · 부품 `02_sol_block_b`(9/9 에 집은 것) · 메모지
**안전** = 속도 **20%** · 정지 버튼에 손 · 테이블 위 **10cm 이상** 높이에서만 회전 · 손목 돌릴 때 **카메라 케이블이 당기는지** 본다(9/22 파손 원인 = J6 회전 당김)

## ① 테이블에 +X · +Y 화살표 붙이기 (5분)

1. 펜던트 왼쪽 메뉴 맨 아래 **`로봇 수동 제어`** → 탭 **`조그 이동`** → 속도 슬라이더 **20%**.
2. 창 위쪽 툴 위치 6값 옆 좌표 기준이 **`base`** 인지 본다. 👁️ base 가 아니면 base 로 바꾼다. [미확인 — 화면에서 확인]
3. **빨간 X 화살표 `+`** 를 짧게 눌러 툴이 2~3cm 움직이게 한다. 👁️ 툴이 간 방향을 본다.
4. 그 방향으로 테이블에 테이프 화살표를 붙이고 **`+X`** 라고 쓴다.
5. **초록 Y 화살표 `+`** 로 같은 일을 하고 **`+Y`** 화살표를 붙인다. 두 테이프는 ㄱ자가 된다.
6. 📝 **"+X 화살표에서 +Y 화살표로 90° 돌아가는 방향"** 을 테이프 옆에 곡선 화살표로 그린다. 이것이 아래 `same` 방향이다.

## ② 툴을 수직으로, RZ 첫 값 (5분)

서버가 보내는 자세는 **RX 180 · RY 0** 이다. 같은 자세에서 재야 한다.

1. `로봇 수동 제어` → 탭 **`사용자 입력`**. [미확인 — 9/9 에 탭 이름만 확인. 6값을 넣고 이동하는 화면으로 추정]
2. 지금 X · Y 는 그대로, **Z 는 테이블 위 10cm 이상**, **RX 180 · RY 0**, **RZ −90** 을 넣고 이동한다.
   - 🔁 사용자 입력이 안 되면: 조그 회전(원형 버튼)으로 RX 가 **180 또는 −180**, RY 가 **0 ± 1** 이 되게 맞춘다. RZ 는 −90 근처면 된다.
3. 📝 **펜던트에 뜬 6값 전부** 적는다(`X Y Z RX RY RZ`). 이 RZ 가 **`rz1`** 이다.
4. 그리퍼를 연다(`DO1` · 입출력 상태 화면 또는 기존 노드 `테스트`).
5. 👁️ 위에서 내려다보며 **두 손가락이 오가는 선**이 어느 테이프와 나란한지 본다.
   - +X 테이프와 나란 → 📝 **`yaw1 = 0`**
   - +Y 테이프와 나란 → 📝 **`yaw1 = 90`**
   - 어느 쪽도 아니면 대략 각도를 적는다(+X 에서 `same` 방향으로 잰 각).
   📷 위에서 한 장.

## ③ RZ 만 +30° (5분)

1. **RZ 만 `rz1 + 30`** 으로 바꿔 이동한다(사용자 입력). X Y Z RX RY 는 그대로.
   - 🔁 조그로 할 때: `미세 제어` 체크(회전 5°) → Rz 회전 버튼을 **6번** 눌러 30° 돌린다.
2. 📝 **펜던트 6값 전부** 적는다. 이 RZ 가 **`rz2`** 이다.
   - 🚨 RX 나 RY 가 크게 바뀌었으면(RX 가 180 에서 −180 으로 바뀐 것은 같은 자세라 괜찮다) 그 값도 그대로 적어 온다.
3. 👁️ 조우 선이 ②에서 **어느 쪽으로 돌았는지** 본다.
   - 테이프 옆 곡선 화살표(+X→+Y) 와 **같은 방향** → 📝 **`sense = same`**
   - **반대 방향** → 📝 **`sense = opposite`**
   📷 위에서 한 장.
4. RZ 를 `rz1` 로 되돌린다.

## ⑤ 파지 깊이 (10분 · 부품 `02_sol_block_b`)

1. 부품을 ①의 테이블에 눕혀 놓는다. 📝 **부품 높이**(눕힌 높이 · 자로 재거나 DB 값).
2. 그리퍼를 **닫는다**(`DO3`). 툴은 ② 자세(RX 180 · RY 0).
3. 조그 Z 로 천천히 내려 **닫힌 조우 끝이 부품 윗면에 살짝 닿게** 한다(종이 한 장이 걸릴 정도 · 3점법 4-4 와 **같은 방식**). 📝 TCP **Z** = **`z_touch`**.
4. Z↑ 3cm → 그리퍼를 **연다**(`DO1`) → 조우가 부품 양옆에 오게 XY 를 맞춘다.
5. 천천히 내려 **9/9 에 집었던 깊이**(조우 끝이 부품 높이의 절반쯤 · 바닥에서 2mm 이상 위)에서 멈춘다. 👁️ 옆에서 본다. 📝 TCP **Z** = **`z_grip`**.
6. 닫아서(`DO3`) 물리는지 본다 → 연다 → Z↑.

```powershell
C:\binpick_venv\Scripts\python bin_picking\tests\grasp_angle_calc.py z --z-touch <z_touch> --z-grip <z_grip> --part-height <높이>
```
✅ 마지막 줄 **`--z-offset …`** 📝
⚠️ 이 값은 **부품 하나 기준**이다. 낮은 부품(높이 6mm 대)에서는 너무 깊을 수 있다 → 9/30 첫 집기는 **z +20 높게**(실행표 v6 B5 그대로).
