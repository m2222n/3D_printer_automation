## 🏭 8/24 (월, 출근) — 🥇 **이번 주 최대 관문 = RGB 동시 촬영**

### 🥇 A. Blaze + ACE2 동시 촬영 (D-0)

**이게 되면 화·수 재택이 살고, 안 되면 이번 주 T3는 없다.**

- 🚨 **선행 = 촬영 스크립트가 없다.** 현행 `blaze_capture_crosssession.py`는 **Blaze 단독**이다
  ⇒ ⭐ **주말/월요일 오전에 코드를 먼저 짜야 한다**(카메라 없이 짤 수 있는 부분)
- 🟢 **유리한 조건** = 7/28에 **두 카메라 동시 연결을 이미 뚫었다**(대역 분리 ACE2 20/Blaze 30) ·
  **extrinsic 확보**(`[+44.7,-0.5,-2.1]`mm·1.78°) · **7/31 오버레이 정합 통과**
- ⚠️ **8/18 조건을 그대로 재현할 것** — 골판지 상자 · DIST 452mm · 형광등 ON · 장당 7종
  🚨 **조건이 바뀌면 depth 쪽이 무효**가 되고 비교가 안 된다
- 📸 **장수 = 8/18과 같은 90장이 목표**, 최소 **30장**(그 이하면 학습이 성립 안 함)
- 🚨 **첫 장 판정 필수** — depth는 8/18 기준(BAND 3~10%), **RGB는 초점·노출**을 눈으로 확인

### 🥈 B. IPC-510 — E2E 러너 이식 + pylon

- T1 러너를 IPC에 올려 **카메라 없이 npy 파일로** 먼저 돌린다(6000·A100과 결과 대조)
- 🚨 **pylon + Blaze 실취득** = *"여기서만 OS 판단이 뒤집힐 수 있다"*(8/14 기록)
- 🥉 브래킷 장착(5분) · 파워 W·보드 모델명 확인

### 🥉 C. 📮 **예승님 자료 확인** (8/21 회신 = *"월요일에 정리해서 보내준다"*)
- 🥇**SDK가 x86 전용인지 ARM인지** — 🚨**Thor가 ARM64**라 x86 전용이면 **받아도 못 돈다**
  ⇒ **T4·T5 경로가 여기서 갈린다.** ⭐단 **3경로 중 1번(펜던트+소켓)은 OS 무관**이라 막히진 않는다
- 한화·그리퍼 담당자 연락처 → 받으면 **조우 두께·TCP payload·"15점 등록"** 을 직접 문의

### 🥉 D. 자투리
로봇 IP 실측(🚨7/31에 **기록과 달랐다**) · TCP↔빈 윗면 거리
