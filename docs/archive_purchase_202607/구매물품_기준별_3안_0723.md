# 지원사업 구매물품 정리 — "기준을 어디까지?" 3안 비교

> **배경**: 대표님 "이전 구매리스트 통으로 바꾸자" + 태민님 "오늘 정리하는 구매물품의 **기준을 어디까지로** 할지?" 질문 드림(답 대기).
> **목적**: 대표님이 '기준'을 어떻게 정하든 즉시 확정할 수 있게 3안을 미리 준비.
> **재원**: 화성 디지털 가속성장(총 6천만, 장비비 한도 ≈2,806만 공급가액, ~10/31).

## 🔑 지금 상황 = 두 방침이 충돌

| 방침 | 내용 | 결론 |
|------|------|------|
| **테스트-후-확정** (태민님 기억) | N6 1대 먼저·웹캠/삼각대 대표님 지급분 먼저 써보고 → 수량 산정 후 리스트업 | "지금은 확정 못 함" |
| **진흥원 압박** (7/14 중간점검) | 집행률 0% → 협약변경 승인 후 **빨리 발주** 안 하면 정산 불인정·환수 | "지금 확정해야 함" |

→ **"기준"을 정한다 = 이 둘을 어디서 타협하느냐**. 아래 3안이 그 선택지.

## 📊 3안 비교표

| 구분 | **A안 — 최소(확정된 것만)** | **B안 — 표준(권장)** | **C안 — 최대(다양화 선구매)** |
|------|---------------------------|---------------------|------------------------------|

| **N6 카메라** | 2대 (대표님 확정분) | 2대 (세척+건조) | 2~4대 (공정별 여유) |
| **웹캠·삼각대** | 제외 (대표님 지급분 테스트 중) | 제외 (테스트 후 추가) | 산업용 웹캠 1~2 추가 |
| **건조대(신규)** | 제외 (방식 미정) | **제작·구매 포함** (건조공정 확정) | 포함 + 방식 A/B 실험장비 둘 다 |
| **Thor** | 유지 | 유지 | 유지 |
| **리모트IO·네트워크** | 유지 | 유지 | 유지 |
| **depth 대안(RealSense)** | 제외 | 제외 | 포함 |
| **예상 장비비(공급가액)** | ~1,300만 | ~1,450만 | ~1,900만+ |
| **한도 2,806만 대비** | 여유 큼 | 여유 있음 | 여유 좁아짐 |
| **진흥원 정합** | ✅ 가장 안전 | ✅ 안전(건조는 협약변경 반영) | ⚠️ 서식 밖 품목多→협약변경 부담 |
| **리스크** | 나중에 또 발주(집행 지연 반복) | 낮음 | 테스트 안 한 것 사서 사장 위험 |

## 🎯 제 추천 = **B안 (표준)**

**이유**: 태민님이 확인한 방침(N6 1대 테스트·웹캠 테스트)을 존중하면서도, 진흥원의 "빨리 발주" 압박에 답이 됨.
- **N6** = 대표님이 이미 "2대"로 정하심 → 확정. 테스트-후-확정 방침과 안 부딪힘(2대는 세척+건조 최소 구성).
- **웹캠·삼각대** = 대표님 지급분 테스트 중이니 이번 리스트 **제외**가 방침에 맞음.
- **건조대** = 태민님이 "추가로 필요한 유일한 항목"으로 짚음 + 대표님 7/16 건조공정 신규 지시 → **이번에 넣는 게 자연스러움**. 단 서식에 건조가 없어 협약변경 반영 필요(대표님 확인).
- **나머지(Thor·리모트IO·네트워크)** = 서식 그대로 유지.

### ⚠️ 건조대 = 아직 못 채우는 칸 (태민님 후속 작업)
건조대는 **치수·방식이 정해져야 견적**이 나옴. 대표님 7/16 지시 = "건조 방식·빌드플레이트 소요 대수·온도별 끈적함 제거 효율". 즉:
- 건조 방식 (에어나이프 무열 vs 저온 열풍) 확정 → 건조대 형태 결정
- Form 빌드플레이트 몇 장이 한 번에 올라가야 하는지 → 건조대 크기
- → 이게 나와야 "건조대 제작" 견적/구매가 확정됨. **주희님과 함께 이번 주 건조공정 설계에서 산출.**
