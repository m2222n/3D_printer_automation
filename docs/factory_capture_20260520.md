> 출발 전 핸드폰에서 빠르게 참고. 공장 도착 직후 바로 시작 가능하도록 구성.

## 📸 촬영 계획 (총 130~140장)

### A. 5종 단일 — 100장 (각 부품 20장)

부품 1종당 20장을 다양한 환경에서:

| 환경 | 장수 | 메모 |
|------|----|------|
| 작업대 위 | 5장 | 다양한 각도 (정면/좌/우/위/비스듬) |
| 트레이/박스 위 | 5장 | 다른 배경 |
| 다른 공장 배경 | 5장 | 컨베이어/후가공대 등 |
| A4 흰 배경 (control) | 5장 | 사무실 분과 비교용 |

→ **20장 × 5종 = 100장**

### B. 멀티 객체 — 30~40장 (다양한 cluttered scene)

| 환경 | 장수 | 설명 |
|------|----|------|
| 2개씩 다양한 쌍 | 9~10장 | 9개 쌍 각 1장 |
| 3개 모음 | 10장 | 다양한 3개 조합 + 각도 |
| 4~5개 모음 | 10장 | cluttered scene |
| **빈/박스 안 던지기** ⭐ | 10장 | 진짜 빈피킹 시뮬레이션 (가장 중요) |

→ **30~40장**

### 🎯 시간 부족 시 우선순위 (최소 80장)

1. **5종 단일 각 10장 = 50장** (필수)
2. **멀티 자연스럽게 20장**
3. **빈/박스 던지기 10장** (occlusion 핵심)

---

## 📐 촬영 핵심 원칙 (5가지)

1. **각도 다양하게**: 정면 / 좌측 / 우측 / 위에서 / 비스듬히
2. **거리 다양하게**: 가깝게 / 멀게
3. **조명 다양하게**: 그늘 / 직사광 / 측광
4. **배경 다양하게**: 같은 부품이라도 작업대 / 트레이 / A4 등
5. **빈/박스 던지기**: 가장 중요 — 자연스러운 occlusion 생성

---

## 🔢 9배치 멀티 객체 조합 (2개씩)

| # | 부품 2개 | 배치 팁 |
|---|--------|--------|
| 1 | Part1 + Part2 | 살짝 떨어뜨림 |
| 2 | Part1 + Part3 | 약간 겹침 |
| 3 | Part1 + Part4 | 멀리 떨어뜨림 |
| 4 | Part2 + Part3 | 부품 회전 다르게 |
| 5 | Part2 + Part4 | 가운데 모아두기 |
| 6 | Part2 + Part5 | 부품 살짝 겹침 |
| 7 | Part3 + Part4 | 좌상/우하 분리 |
| 8 | Part3 + Part5 | 자연스럽게 |
| 9 | Part4 + Part5 | 한 부품이 다른 부품 옆 |

## 🏭 공장 도착 후 작업 순서

### 1단계: 환경 파악 (5분)

- 활용 가능한 표면 둘러보기:
  - 작업대 / 부품 트레이 / 빈 박스 / 컨베이어 / 후가공대
- 조명 위치 확인 (그늘 vs 직사광 자리)

### 2단계: 5종 단일 촬영 (1~1.5시간)

부품 1종씩 진행. 한 부품 다 끝내고 다음 부품:

```
Part1 시작
 → 작업대 위 5장 (정면/좌/우/위/비스듬)
 → 트레이 위 5장
 → 다른 배경 5장
 → A4 흰 배경 5장 (control)
 → Part1 완료 (20장)
 → Part2 시작 ...
```

### 3단계: 멀티 객체 촬영 (1시간)

```
2개씩 9쌍 (Part1+2 / Part1+3 / ... / Part4+5)
 → 각 쌍 1장씩 = 9~10장

3개 모음
 → 다양한 3개 조합 + 각도 = 10장

4~5개 모음
 → cluttered scene = 10장
```

### 4단계: 빈/박스 던지기 ⭐ (15~20분)

**이게 가장 중요한 데이터**:

- 박스에 부품 2~5개 던지기 (자연스럽게)
- 위에서 핸드폰으로 촬영
- 부품끼리 자연 occlusion 발생
- 진짜 빈피킹 환경 시뮬레이션

→ **10장** (다양한 던짐 결과)

## 📝 촬영 시 주의사항

### 좋은 예
- ✅ 부품이 사진 중앙 부근 (가장자리 잘림 X)
- ✅ 부품 전체가 사진 안에 들어옴
- ✅ 초점 맞음 (흐릿 X)
- ✅ 그림자 자연스러움 (강한 역광 피하기)

### 나쁜 예
- ❌ 너무 멀어서 부품 작게 보임 (10% 이하)
- ❌ 부품 일부가 사진 밖
- ❌ 흔들림으로 흐림
- ❌ 같은 배치 같은 각도 반복 (다양성 X)

### 핸드폰 설정 권장
- 그리드 켜기 (구도 안정)
- 자동 초점 on
- 자동 노출 on
- HDR off (RAW 가까운 데이터)

## ❓ FAQ

**Q: 부품 라벨 (P1~P5)이 헷갈리면?**
- A: 5/11 P1~P5 라벨은 추정값. 학습으로 클래스 분리만 되면 OK. 일관성만 유지 (한 번 Part1로 정한 부품은 끝까지 Part1)

**Q: 같은 부품 20장 다 다른 각도여야 하나?**
- A: 가능한 다양하게. 똑같은 사진 2장 있어도 큰 문제는 아님 (Roboflow에서 자동 중복 제거).

**Q: 빈 박스가 공장에 없으면?**
- A: 트레이 / 그릇 / 임시 박스 아무거나 OK. 핵심은 "**부품을 던져넣어 자연 occlusion 생성**"

**Q: 사진 시간 너무 오래 걸리면?**
- A: 우선순위 1단계 최소 80장만으로도 v2 학습 가능. 무리하지 말 것.

**Q: ACE2 / Blaze 카메라도 같이?**
- A: 오늘은 No. 트랙 2 YOLO 데이터셋이 목적이라 핸드폰만으로 충분. 트랙 1 depth 카메라는 ACE2 렌즈 인수 후 별도.
