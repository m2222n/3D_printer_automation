## 0. 전체 프로젝트 그림 (제일 먼저 맞춰야 할 컨텍스트)

### 우리 회사가 만드는 것
점자프린터 부품을 3D 프린터로 찍어서 후처리까지 완전 자동화하는 생산 라인. 부품 약 29종 / 한 라인.

### 공정은 두 부분으로 나뉨

```
─── 전공정 (3D 프린터 → 세척 → 경화) ──┐
                                       │
                                       ▼
                            ─── 후공정 (빈피킹 → 후가공 → 적재)
```

| 구분 | 장비 | 역할 |
|------|------|------|
| **전공정** | 3D 프린터 4대 (Form 4) + 세척기 2대 + 경화기 | 부품 출력 → 레진 세척 → UV 경화 |
| **후공정** | 빈피킹 비전 + 협동로봇 (HCR-10L) | 빈에 쌓인 부품을 집어서 후가공 |

### 시연 순서 — 대표님 방향성 (중요)
**1순위: 전공정 시연 먼저** ⭐
- 한솔코에버에서 **현재 그리퍼를 빌드플레이트 집는 용도로 교체** 진행 예정
- 3D 프린터 출력 완료 → 그리퍼가 빌드플레이트 픽업 → 세척기 → 경화기 흐름
- 한솔과 조만간 회의 (그리퍼 교체 안건)

**2순위: 후공정(빈피킹) 시연 — 가을(9~10월)**
- 대표님 현재 판단: "빈피킹 시연은 시간이 좀 걸린다"
- **~8월까지 학습을 잘 시키는 게 우리 미션**
- 가을에 협력사 페이스로 실 로봇 연동 시연

### 즉, 6~8월 우리 팀의 진짜 미션
**카메라 인식 모델을 8월 안에 "잘" 학습시켜 두기**.
"잘" = mAP 수치 자랑이 아니라 **다양한 환경/조명/occlusion에서도 견고하게 인식** = 도메인 일반화.

→ 이번주부터 8월까지는 "수치 0.99 달성"이 아니라 **"진짜 현장에서 통하는 모델"을 만드는 단계**.

## 1. 컨텍스트 — 후공정(빈피킹)에서 우리가 하는 것

3D 프린터로 찍어낸 부품을 **빈(통)에 무작위로 쌓여 있는 상태**에서 협동로봇이 하나씩 집어내는 시스템.

```
[빈에 쌓인 부품] → [카메라 인식] → [좌표 출력] → [협동로봇이 집음]
        └─ 우리 책임 ─┘            └─ 한솔코에버 책임 ─┘
```

우리가 책임지는 부분 = **카메라 인식 + 좌표 출력**.
협력사(한솔코에버)가 받아서 로봇 모션으로 연결.

### 두 가지 접근을 병행 중
| | 트랙 1 (6DoF Pose) | 트랙 2 (YOLO 2D) |
|---|---|---|
| 방식 | CAD 모델 매칭 (Open3D, FPFH+ICP) | 딥러닝 객체 검출 (YOLO) |
| 좌표 | 6자유도 (회전 포함) | 6요소 (x,y,z,edge,angle,label) |
| 데이터 | CAD 29종 + 합성 | 실 부품 촬영 + 증강 |
| 현재 | 인프라 완성, 검증 보류 | **메인 트랙, v2 학습 완료** |

협력사 권고 + 산업 표준 = **YOLO 트랙이 현실적**이라 메인으로 전환.

## 3. 수치 이해 — 각 지표 의미와 중요도

### 🥇 가장 중요: **Recall** (재현율) — "안 놓쳤나"
```
Recall = TP / (TP + FN)
       = (찾은 부품) / (실제 있던 부품)
```
- **빈피킹 = 부품 놓치면 빈에 남음 = 실패**
- 그래서 빈피킹은 Recall이 Precision보다 중요

### 🥈 두 번째: **mAP50** — "박스 잘 잡았나"
- IoU 0.5 이상으로 박스가 겹치면 OK
- 0.99대 = 거의 완벽 (단, 단일 환경 valid라 "외운 것" 가능성 있음 → 도메인 갭 검증 필요)

### 🥉 세 번째: **mAP50-95** — "박스 정확히 잡았나"
- IoU 0.5~0.95 10개 임계값에서 mAP 평균
- 빡빡한 기준 → bbox 위치 정밀도
- 빈피킹에서 박스 중심이 어긋나면 그래스프 좌표가 어긋남 → 중요
- 우리 v2 = 0.72~0.75 = 양호

### ✓ 보조: **Precision** — "오탐 적나"
- 없는 부품을 부품이라고 잘못 잡는 빈도
- 빈피킹은 Recall이 더 중요하지만 너무 낮으면 헛손질

### IoU (Intersection over Union) — 기준 개념
- 예측 박스 ∩ 정답 박스 / 예측 ∪ 정답
- 0.5 이상이면 "맞췄다"고 침 (mAP50 기준)
