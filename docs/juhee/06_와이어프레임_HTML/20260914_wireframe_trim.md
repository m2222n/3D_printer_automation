## 4. 줄인 글

화면 안 설명문 약 20곳을 한 줄 이하로. 대표적으로:

- `이미 입력한 파트는 건드리지 않습니다. 대부분 전부 OK 이고…` → 삭제
- `묶음째 이동 1건입니다 (부품 N건이 아닙니다). 물리 이동은 없습니다.` → 삭제
- `시작·중지·완료는 설비로 나가는 명령입니다. product_event 에 source=MANUAL 로 남습니다.` → 삭제
- `위에서 하나를 고르고, 비어 있는 설비의 투입을 누르면…(FIFO)` → `FIFO · 출처마다 앞의 것부터`
- `v_control_menu · 공정 순서대로`, `목업에 줄을 더하면 여기가 늘어납니다` → 삭제(설계 메모)
- 확인 다이얼로그 6개의 스키마 설명(`judgement 에 NG 가 기록되고 part_scrap 으로…`) → 한 줄
- 미설계 페이지 3개(작업 지시 · 이력·품질 · 설비 관리) 안내문 → 한 줄

되돌릴 수 없는 동작(`되돌릴 수 없습니다`, NG 폐기, 정원 초과 경고)의 경고 문구는 **그대로 뒀다**.
