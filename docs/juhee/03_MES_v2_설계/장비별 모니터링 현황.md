## 신호 흐름 (프린터 한 장 기준)

```
/local/print 성공 ──B1──▶ Spawn(cmd_id)            unit 생성 · RK-PRE-PRT → PRT-n 은 로봇이 옮김
Formlabs 폴링 15s ──B2──▶ State(RUN | HOLD)        위치 안 바꿈
제어 cmd_status=40 ──B3──▶ State(DONE)              ready_at 계산 · 채번 P
로봇 206==1 ──────B5──▶ Moved(printer-n → wash-m)  위치 확정 · 채번은 이 시점
카메라 MQTT ───────B4──▶ State(RUN | DONE)          세척·경화
작업자 화면 ───────W1~5─▶ Split · Moved · State · judgement · command_log
```

위치를 바꾸는 것은 `Moved` 뿐이다. 카메라(B4)·프린터 API(B2)는 상태만 바꾼다.
