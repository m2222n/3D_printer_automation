# 🔴 기존 코드에서 나온 발견

## 1. M2b 대상 파일이 폐기 선언본이었다

`bin_picking/src/communication/modbus_server.py` 머리에 폐기 선언이 있다 (2026-07-30, 실측 확인).

```
⚠️⚠️ 폐기 예정 (DEPRECATED, 2026-07-30) — 빈피킹에 쓰지 말 것
  | 이 파일           | 확정판(7/27)                        |
  | 131~137 = 좌표    | 131~135 = 이송 파라미터(설비ID·시간) |
  | 150 = 로봇→PC 상태 | 150 = PC→로봇 송신 트리거(방향 반대) |
  | 200/206 없음      | 200 Robot Ready / 206 Robot Moved   |
```

정본은 `sequence_service/app/cell/modbus_protocol.py` 이고 **방향이 뒤집혔다.**

|  | 실측 |
| --- | --- |
| 우리 역할 | **마스터** — `ModbusTcpClient` 로 로봇에 직접 쓴다 (슬레이브 우려 불식) |
| 완료 신호 | **레지스터 206** = Robot Moved |
| 발행 지점 | `robot.py:578 STEP0070` → `_complete_task` |

🚨 **파생** — `CLAUDE.md` 의 Modbus 절이 **폐기된 맵**을 싣고 있다.

방향이 반대이고, 좌표는 애초에 Modbus 로 가지 않으며, `200`/`206` 이 빠져 있다. **별건으로 정정 필요.**

## 2. M2a — vision 상태감시가 실질 미가동

| 위치 | 타입 |
| --- | --- |
| `wash_detector.py:111` (발행) | `timestamp` = **float** |
| `web-api/app/vision/schemas.py:38` (수신) | `timestamp` = **str** |

`mqtt_client.py:86-88` 의 `except Exception` 이 `ValidationError` 를 삼켜 **실물 메시지가 전건 사라진다.**

시뮬레이터는 `isoformat()` 을 보내 통과하므로 **테스트로는 안 잡힌다.**

⚠️ **이 버그를 고치기 전까지 vision 상태감시는 실질 미가동이다.**

대응은 스키마를 `float | str` 로 넓히는 쪽 — 발행 측을 고치면 현장 기기 4대 재플래시가 필요하다.

## 3. `PostProcStage` 값 순서가 실제 진행 순서와 다르다

```
값 정렬 :  CURE_WAITING 10 · CURING 20 · CURE_DONE 30 · WASH_WAITING 40 · WASHING 50 · WASH_DONE 60 · OUTPUT_DONE 70
실제 진행:  WASHING 50 → WASH_DONE 60 → CURE_WAITING 10 → CURING 20 → CURE_DONE 30 → OUTPUT_DONE 70
```

**세척 → 경화 전환에서 값이 60 → 10 으로 역행한다.** 실행 코드가 값으로 순서를 판단하지 않으므로

(각 시퀀스가 명시적으로 다음 단계를 대입) **지금 버그는 아니다.** 다만

- `ORDER BY post_proc_stage` 로 진척을 정렬하면 **틀린 순서가 나온다**
- 신규 스키마로 옮길 때 이 값을 `step_order` 로 그대로 쓰면 공정 순서가 뒤집힌다

⇒ 📌 **마이그레이션 시 값이 아니라 `route` 의 MAIN 엣지로 순서를 잡을 것.**

## 4. `automation_comm_config` 는 모델에 없다

`repository.py:128` 이 런타임에 `CREATE TABLE IF NOT EXISTS` 로 만든다.

**`models.py` 만 보고 스키마를 파악하면 놓친다** — 기존 코드를 조사할 때 주의할 지점.

## 5. FK 제약이 기존 양쪽 모두 0건

`automation_log.cmd_id` → `print_command.cmd_id`,

`binpick_detections.scene_pk` → `binpick_scenes.id` 둘 다 **컬럼만 있고 FK 제약이 없다.**

신규는 FK 22건을 건다 — 이관 시 **고아 행이 걸려 INSERT 가 막힐 수 있다.**
