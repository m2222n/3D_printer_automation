# 랙 구조 — `랙 > 칸 > 자리`

- 현재 랙마다 **칸 2개 × 자리 4개 = 8장**. 랙 개수·칸 수·자리 수 모두 가변
- YAML `slots: [4, 4]` → `node.capacity` 는 **합계로 자동 계산**. 직접 쓰지 않음
- 불균등한 칸(`[6, 6, 4]`)도 표현 가능
- 랙 ID 체계에 `-01` 접미. 증설 = `-02` 추가
- 트레이 랙(`count_by_group`) — 묶음(`group_id`) 단위로 용량 계산

## 칸은 선입선출(FIFO)

- `pos_no` 는 절대 좌표가 아니라 **앞에서 몇 번째** — 대기열 순번
- 앞의 것이 빠지면 뒤가 밀려 내려오므로 **순번을 당긴다** → 점유는 항상 1..n 연속
- 각 칸에서 꺼낼 수 있는 것은 **1번 하나뿐**. 나머지는 묻혀 있음
- 절대 위치로 굴리면 1번 자리가 영구히 비어 랙이 서서히 못 쓰게 됨
- `slot_access` = `FIFO`(기본) / `LIFO` / `RANDOM` — 랙의 물리 구조를 데이터로
- `slot_fill` = `SEQUENTIAL`(기본) / `BALANCED` — 어느 칸부터 채울지
- **총 용량이 남아도 특정 칸이 차면 못 받는다** → `full_slots` 를 함께 낸다
