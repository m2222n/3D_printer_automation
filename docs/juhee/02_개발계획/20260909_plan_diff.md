## 🔴 M2a — 실물이 미가동이라는 발견

9/7 에는 없던 내용이다.

디바이스는 `timestamp` 를 **float** 로 보내는데(`wash_detector.py:111`)
스키마는 **str** 을 요구한다(`web-api/app/vision/schemas.py:38` — 실측 확인).
`mqtt_client.py:86-88` 의 `except Exception` 이 `ValidationError` 를 삼켜 **실물 메시지가 전건 사라진다.**
시뮬레이터는 `isoformat()` 을 보내서 통과하므로 **테스트로는 안 잡힌다.**

⚠️ **이 버그를 고치기 전까지 vision 상태감시는 실질 미가동이다.**
대응은 스키마를 `float | str` 로 넓히는 쪽 — 발행 측을 고치면 현장 기기 4대 재플래시가 필요하다.

## 채번 규칙이 구체화됐다

9/7 은 *"채번 지점은 M3a 단 한 곳"* 까지였다. 9/9 는 조건 두 개로 못박았다.

```
① from_node 에서 status == 'DONE' 이었을 것
② unit.named_at != from_node      — 그 노드에서 아직 이름을 받지 않았을 것
```

⚠️ **`edge_kind` 로 판별하면 틀린다** 는 발견이 붙었다. 되주차 경로에서도 세척기를 떠나는 것은

⇒ `status` 가 이미 "가공했는가"를 알고 있고, `edge_kind` 는 순서 계산 전용이다.
