셀A WS 끊김 셀B WS 끊김 인증: 미설정 기준 = 응답시간 3초 이내 (평균·최대)

1. 접속 설정

시험 서버에서 직접 접속(localhost)하면 로그인 없이 됩니다. 다른 PC에서 접속하면 로그인 후 토큰이 자동으로 쓰입니다. 화면은 셀A 설비 상태 채널(/api/v1/vision/ws)과 셀B 빈피킹 채널(/api/v1/binpick/ws) 두 개를 함께 구독합니다.

2. 사전조건 — 설비 상태 초기화

3. 시험데이터 — 이벤트 목록 (셀A 설비 상태 변경 + 셀B 빈피킹 인식 결과)

파일 없음

형식: {"events":[{"seq":1,"cell":"A","kind":"vision","camera_id":"wash_1","status":"wash_running"}, {"seq":3,"cell":"B","kind":"binpick","scene_id":"…","report":{…빈피킹 모듈 payload…}}, …]}
셀A: 카메라 = wash_1 · wash_2 · cure_1 · cure_2 · 상태 = wash_idle/wash_running/wash_complete · cure_idle/cure_running/cure_complete · 같은 설비의 연속 이벤트는 상태가 바뀌어야 합니다(같은 상태는 서버가 변경으로 치지 않음).
셀B: report는 빈피킹 모듈이 서버에 보내는 인식 결과 그대로(POST /api/v1/binpick/reports) · 정식 시험 데이터는 규격서에 해시로 고정된 파일을 씁니다.
