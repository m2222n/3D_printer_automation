## 1. 촬영 방식 = 자동 저장 스크립트 (7/14 최종 확정)

**여러 방법 검토 끝에 스크립트로 결론.** 경위(다음에 헤매지 말 것):
- ❌ **IDE 영상 녹화** = 인텔 Mac에서 **ffmpeg 실행 불가**(팝업 "ffmpeg를 실행하지 못했습니다"). mp4 변환 단계에서 죽음. → 이 Mac에선 영상 저장 불가(공장 Windows면 됐음).
- ❌ **IDE Dataset Editor** = 캡처 버튼을 **매번 눌러야** 함 + USB 짧아 카메라 손으로 들어야 해서 흔들림.
- ❌ **초점 링 테이프 고정 후 자동촬영** = USB 짧아 고정 위치 확보 어려움.
- ✅ **자동 저장 스크립트 `openmv_capture_v3.py`** = IDE 없이 스크립트 하나로 초점 확인 + 자동 저장. USB 짧고 손으로 드는 상황에 최적.

**v1 깨짐 해결**: 어제 `openmv_capture.py`는 일반 REPL base64라 JPEG 손상(미리보기 못 엶). v3는 **raw REPL(Ctrl-A) + 디코딩 검증 후 PNG 저장**(깨진 프레임 스킵) → **PNG 정상 열림 검증 완료**.

**스크립트 위치**: 저장소 `OpenMV/scripts/openmv_capture_v3.py` (Mac엔 `~/Desktop/openmv_capture_v3.py`로 복붙). 의존성 = pyserial + opencv-python(미리보기·검증용, Mac에 설치 완료).

**사용법**:
1. IDE **완전 종료(⌘Q)** — 안 그러면 `Resource busy`.
2. `python3 ~/Desktop/openmv_capture_v3.py` → 라벨 입력.
3. 창이 **PAUSED**로 시작 → **FOCUS 숫자**(노랑) 보며 렌즈 돌려 초점 최대로(높을수록 선명).
4. **p** = 촬영 시작(3초 자동 저장) / 다시 p = 정지 / **s** = 즉시저장 / **q** = 종료.
5. 저장 → `~/Desktop/openmv_0714/<라벨>/` (PNG).

⚠️ 미리보기는 base64 왕복(115200)이라 **끊김 = 정상**(구조 한계, 못 고침). 초점은 정지화면 선명도로 판단 OK. 매끄러운 라이브뷰는 IDE만 가능(단 IDE는 촬영 자동화 안 됨).
⚠️ 포트 14201 아니면 스크립트 PORT 수정(`ls /dev/cu.usbmodem*`).
⚠️ 어제 깨진 `~/Desktop/openmv_capture/*`(test 포함) 삭제.

## 2. 촬영 대상 = 6 클래스

| 클래스 | 상태 | 목표 | 우선순위 |
|--------|------|------|----------|
| wash_idle | 세척기 대기(꺼짐) | 40~50 | 3 |
| wash_running | 세척 중 | 40~50 | 2 |
| **wash_complete** | 세척 완료 | **60+** | **1** (어제 부족) |
| cure_idle | 경화기 대기 | 40~50 | 3 |
| cure_running | 경화 중(UV) | 40~50 | 2 |

**합계 목표 = 약 300~400장.** 시간 부족하면 우선순위 1 → 2 → 3 순.

## 3. ⭐ 촬영 = 2개 위치로

각 클래스(6개)를 **두 위치**에서 나눠 촬영. 위치마다 목적이 다름.

### 위치 ① 실운영 고정 위치 (⭐ 최우선 — 지정된 카메라 세팅 위치)
- **실제 배포 시 카메라가 볼 바로 그 뷰** = 실전에서 통하는 모델의 필수 데이터.
- 카메라 **고정**, 환경만 변주: 조명 on/off, 문 열림/닫힘, 반사광 유무.
- 이 고정 뷰에서 **idle/running/complete 상태 차이가 실제로 구분되는지**가 관건(어제 밝기차 미묘했음 → 현장서 눈으로 확인).
- 목표: 클래스당 20~30장.

### 위치 ② 장비 잘 보이는 위치 (보조 — 상태 특징 선명)
- 자유 구도, **각도(정면/좌/우) × 거리(가까이/멀리)** 다양화.
- 모델이 상태 특징을 일반화하도록 돕는 데이터.
- 목표: 클래스당 20~30장.

### 공통 규칙 (배경 외우기 깨기)
- **한 조건에서 5장 이상 금지** → 5장 찍으면 조명/문/각도/거리 바꾸기.
- 거리 바꾸면 초점 재확인(위치 ②). 위치 ①은 고정이라 초점 1회만.
- ⭐ 위치 ① 데이터는 배경 고정돼도 OK(실전이 그러함), 단 상태 라벨은 정확히.
